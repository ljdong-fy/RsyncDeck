# RsyncDeck

[下载 Windows x64 安装包](https://github.com/ljdong-fy/RsyncDeck/releases/tag/v1.0.0) · [English](README.en.md)

RsyncDeck 是 Windows 上的 rsync 图形工具，用于把本地目录或文件同步到另一块磁盘、SSH 服务器或 rsync 模块，也支持从远端同步回本地。

首次启动会跟随 Windows 界面语言。可从顶部「语言 / Language」菜单选择简体中文或 English，选项会保留到下次启动。

## 开始使用

1. 双击 `RsyncDeck-1.0.0-win-x64-setup.msi`，选择安装目录，然后从开始菜单打开 RsyncDeck。已内置 .NET Desktop Runtime、rsync 和 OpenSSH。卸载时可双击安装目录中的 **Uninstall RsyncDeck**，已保存的会话会保留。
2. 新用户默认使用内置 rsync。升级时会保留有效的自选 rsync 路径；可从「文件 → 使用内置 rsync」切回。首次连接自己的 SSH 服务器时，仍需有效的登录凭据和已核对的主机公钥。本工具使用非交互 SSH；内置 OpenSSH 的 `ssh.exe` 和 `ssh-keygen.exe` 在 `engine\usr\bin`，沿用 Windows 用户目录下的 `.ssh` 配置。
3. 填好来源、目标，可直接「同步预览」，也可输入名称后「保存会话」。例如 `D:\Assets` 到 `user@server.example:/data/assets`。至少一端须为本地路径。目录模式同步的是来源目录的内容；单文件模式的目标仍然是目录。
4. 确认后点「同步并校验」。传输成功后，程序按本次同步选项自动进行只读复查；还有待处理的变更时会提示差异。未开启内容比较时，复查不会强制计算校验和。要检查同步规则可能跳过的内容差异，可选择「文件 → 校验文件内容」，此操作会读取两端文件且不修改目标。

使用「会话 → 迁移本机 Grsync 会话」可直接读取当前 Windows 用户的 `.grsync\grsync.ini`，复制来源、目标、选项、附加 rsync 参数和前后命令，保留原勾选状态。同名会话不会被覆盖，迁移也不会执行同步或命令。镜像删除仍会先模拟并在发现待删除项时请求确认。

普通「导入」可以选择其他 `grsync.ini` 或 RsyncDeck JSON 文件：会保留命令文本，但关闭镜像删除和命令执行。导出包含路径和参数，不包含前后命令。发布软件时不需要附上会话文件。

## 选项

- **设为启动会话**：从会话列表选择已保存的会话，再点击此按钮。下次打开软件会载入该会话，等待你手动操作。「会话 → 启动时打开空白会话」可撤销此设置。
- **恢复默认选项**：重置当前表单的同步选项，保留会话名称、来源和目标。点击「保存会话」后才会写入已保存的会话。
- 可点击「打开日志目录」查看最近一次运行的临时日志。下次运行会覆盖 `latest.log`，退出时清理；异常退出留下的文件会在下次启动时清理。

- **基本选项**：保留时间、权限、所有者和组，显示进度、详细输出、删除目标端多余项、跳过规则、文件系统边界及 Windows 兼容模式（1 秒修改时间容差）。镜像删除会先模拟并确认。
- **高级选项**：按文件内容比较（预览、同步和传后复查时使用校验和比较内容）、压缩、设备文件、数字 UID/GID、符号链接、硬链接、保留中断文件、备份、SSH 端口，以及附加 rsync 参数。
- **附加选项**：单文件模式、同步前后本机 CMD 命令。只有实际同步且勾选时才运行命令；模拟和只读校验不会运行。同步后命令在传输成功后、复查前执行。命令从当前 Windows 用户的主目录运行。

附加参数示例：

```text
--exclude=*.tmp --bwlimit=4096 --stats
--exclude="目录名含空格/" --timeout=120
-rt --no-p --no-o --no-g --chmod=Du=rwx,Dg=rx,Do=rx,Fu=rw,Fg=r,Fo=r
```

附加参数支持常用选项，不接受覆盖模拟模式、删除保护、连接命令或来源目标的参数。包含与排除规则也应用于内容校验。目标文件系统和远端权限会影响设备文件、链接、所有者等选项的可用性。备份模式与镜像删除需分开执行。

会话设置位于 `%LOCALAPPDATA%\RsyncDeck`，临时日志位于 `%TEMP%\RsyncDeck\logs`。升级后会清理旧版自动生成的任务日志。如果本机保存过早期 GrsyncNext 设置，RsyncDeck 首次使用时可以读取这些会话，之后单独保存。普通取消不会回滚已经写入目标的文件。


## 传输进度

勾选「基本选项 → 显示传输进度」后，「同步并校验」会先只读扫描待传文件，再显示当前文件和整批传输进度。整批百分比按预计待传文件大小估算；文件清单有变动、总量不再可靠时，界面会显示总量待定。rsync 成功退出后才会显示传输 100%，传后复查仍单独进行。同步预览和独立校验显示当前阶段与结果。无需进度条时，可关闭此选项来跳过为估算进度而做的扫描；镜像删除仍会先模拟。

## 连接与代理

在「连接与代理」选 SOCKS5 或 HTTP CONNECT，填本地代理软件显示的地址和端口（例如 `127.0.0.1:1080`；以实际显示为准），再保存会话。默认直连。此功能使用内置 rsync，适用于 `user@host:/path` 形式的 SSH 任务，模拟、传输和只读校验都经过同一个代理。只支持无需用户名和密码的代理；本地同步和 rsync 模块不走此代理。

公开分发 MSI 安装包时，请在同一下载页提供配套 `RsyncDeck-1.0.0-third-party-sources.zip`。普通使用不需要下载源码包。组件出处和版本见 `THIRD-PARTY.md`。
